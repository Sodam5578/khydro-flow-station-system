시뮬레이션 모드 (가상 발송)

웹 시스템에 접속하지 않아도 24시간 백그라운드 품질감시 엔진이 원본 관측자료를 실시간 감시하여, 사용자가 설정한 횟수 이상 연속 결측 시 자동으로 담당자 이메일 알림을 발송합니다.

💡 팀원 전체 수신을 위한 Brevo 무료 API Key 발급 방법 (1분 소요):
1. brevo.com 접속 후 무료 가입 (구글 또는 이메일)
2. 로그인 후 우측 상단 [내 계정명] ➡️ [SMTP & API] ➡️ [API Keys] 탭 클릭
3. [Generate a new API key] 클릭 후 발급된 키(xkeysib-...)를 복사하여 위 입력창에 붙여넣기
4. 발신처 이메일에 Brevo 가입 시 사용한 이메일(예: seyoo123456789@gmail.com)을 입력하면 어느 팀원 이메일(네이버/기술원 등)로도 즉시 발송됩니다!
🔒 조회 전용 모드: 이메일 알림 서비스 설정은 최고 관리자(admin) 계정으로만 변경할 수 있습니다.
